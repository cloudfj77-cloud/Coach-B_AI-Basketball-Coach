# 低成本使用方案评估

核查日期：2026-09-26。用户只有普通 Apple ID、没有云服务器；当前仅评估，没有购买或部署。这里是方案建议，不代表已经切换技术路线或完成相应实现。

## 手机入口

| 方式 | Apple 费用 | 持续使用的取舍 |
| --- | --- | --- |
| 现有原生 App + 普通 Apple ID | 无开发者年费 | 适合试装验证；Personal Team 签名配置 7 天到期，可能需重新构建安装，不符合长期尽量不碰电脑的目标 |
| 原生 App + Developer Program | 99 美元/年，或当地货币结算 | 可继续完善 TestFlight 分发；不是买完就自动获得永久安装，仍需维护构建和分发 |
| 云端手机 Web App，添加到主屏幕 | 无原生应用签名年费 | 从手机进入并选择视频，不要求 Mac 开机；需要新增手机网页界面；大视频上传期间仍应保持前台 |

Apple 的[会员对比](https://developer.apple.com/support/compare-memberships/)明确说明 Personal Team 的 7 天限制与年费；Apple 提供[将网站作为 iPhone App 打开](https://support.apple.com/guide/iphone/open-as-web-app-iphea86e5236/27/ios/27)的系统入口。

建议：先不付 Apple 年费。现有原生代码保留，可用普通 Apple ID 做短期实机验证；如果最优先考虑省钱、长期手机直接用，选择云端手机 Web App 是另一条可行路线，需用户选择后再开发。

## 云端费用与适配

当前架构由 CPU 运行 FFmpeg，AI 通过 API 使用；不需要自购 GPU 服务器。2 核 2 GB 可作为单任务处理的试验起点，实际 iPhone HDR 片源必须测内存峰值；4 GB 更有余量。这里只是容量建议，不是已在这两种机器上完成性能测试。

| 方案 | 官方可核验价格参考 | 对现有项目的影响 |
| --- | --- | --- |
| 腾讯云中国内地通用轻量，2 核 2 GB / 60 GB 磁盘 | 官方调价公告列价 52 元/月 | 能挂载现有文件和数据库；视频处理性能、网络与域名条件需部署前验证 |
| 腾讯云中国内地通用轻量，2 核 4 GB / 90 GB 磁盘 | 官方调价公告列价 80 元/月 | 更多转码内存和存储余量 |
| Railway Hobby | 每月至少 5 美元，包含等额资源用量；超出另计 | 当前套餐持久卷上限 5 GB，对连续存原视频过小；需要改为对象存储，不能按 5 美元固定总价承诺 |

来源：[腾讯云官方列价公告](https://cloud.tencent.com/document/product/1207/119345)、[Railway 官方价格](https://railway.com/pricing)。腾讯价格是公开刊例参考，不是当前账号的购买报价；实际地域、新用户活动和续费价以结算页为准。没有把无法验证的抢购广告当作长期预算。

## AI 成本

若主要在国内使用，可把阿里云百炼视觉模型纳入质量和成本对比。例如北京地域 Qwen3-VL-Plus 在单次输入不超过 32K Token 的档位，输入 1 元/百万 Token、输出 10 元/百万 Token；更长输入按更高档位。来源：[官方模型价目](https://help.aliyun.com/zh/model-studio/model-pricing)。

不能直接据此报“每段视频多少钱”：分辨率、抽帧频率、分段数量与复核次数都会改变用量，便宜模型的球员/进球识别效果也尚未测试。建议先限定 20 元的测试预算，用 3 段已人工标注视频测漏检率、误判率与账单，再估算月费。20 元是建议的试验额度，不是月费报价，也尚未配置技术上的费用上限。当前代码仅接入 OpenAI 格式的 Responses API，百炼适配尚未实现。

## 存储与预算

以每天约 0.5 GB 原片估算，一个月仅原片新增约 15 GB，还未包含预览、集锦和备份。需要确定保留策略或增加对象存储，不能长期依赖几 GB 免费磁盘；任何自动删除原片的策略都应先由用户选择。

保守试用预算可按服务器 52–80 元/月，加一次性 20 元 AI 评估额度，即首月 72–100 元，再单列域名、备份和超额流量。这个区间是规划估算，不是固定总价。先测小视频和真实 HDR 原片，再决定年付、扩容或开发者年费。
