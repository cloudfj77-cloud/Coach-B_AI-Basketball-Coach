# 部署与安装

先免费自用可选择[个人 Mac 模式](free-mac.md)：手机直接传视频给 Mac，电脑需保持开机，暂不调用付费 AI。

## 个人云端服务

需要能持续运行容器、包含 FFmpeg、挂载持久磁盘的服务环境。此项目尚未绑定云厂商，没有购买主机或启用付费资源。

1. 构建仓库根目录的 Dockerfile。
2. 为 `/data` 挂载持久磁盘，备份整个目录。
3. 设置 `APP_TOKEN` 为至少 32 字符的随机私人令牌，不提交到 Git。
4. 在 HTTPS 反向代理后运行 8765 端口。代理应允许最大 2 GB 上传，配置合适超时；公网只开放 HTTPS。
5. 可选设置 `OPENAI_API_KEY` 和 `OPENAI_MODEL`（默认 `gpt-4.1-mini`）。密钥只保存在服务端环境。没有密钥时仍可手动核对与剪辑。
6. 在 App 设置填入 HTTPS 地址与私人令牌。
7. 先用小视频验收上传、核对、重开 App、导出、相册保存，再测较大的 HDR 原片。

当前是个人版服务，不应直接作为公开多用户平台。多用户版本需独立账号、训练所有者校验与对象存储。

## 真实 iPhone 安装

目前是源代码和 Xcode 工程，不是已签名的安装包。

1. 在 Xcode Accounts 中配置用户自己的 Apple 开发身份。
2. 在 Signing & Capabilities 选择 Team，按需要调整 Bundle Identifier。
3. 连接并信任 iPhone，选择设备，按 Xcode 提示完成开发者模式与运行配置。
4. 长期分发可使用 TestFlight，需要相应 Apple Developer 资格与 App Store Connect 配置。项目尚未开通这些服务。

不要在聊天中发送 Apple 密码、访问令牌或 API 密钥。签名和云端地址确定后，再做真实手机端到端验证。
